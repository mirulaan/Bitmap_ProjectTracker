# Database Subsystem Blueprint

## Overview
The `database/` directory contains schema migrations, seeders, and local SQLite database files managing data persistence for **Bitmap Project Tracker**.

## Subdirectories & Boundaries
- migrations: [./migrations/README.md](./migrations/README.md) - Relational schema migrations and DDL table definitions.
- seeders: [./seeders/README.md](./seeders/README.md) - Factory templates and default initial project seeders.
