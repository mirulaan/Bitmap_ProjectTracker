# Application Resources Blueprint

## Overview
The `resources/` directory contains frontend presentation resources, Blade views, raw stylesheets, and JavaScript source bundles for **Bitmap Project Tracker**.

## Subdirectories & Boundaries
- js: [./js/README.md](./js/README.md) - Vite JavaScript source files and frontend entrypoint.
- views: [./views/README.md](./views/README.md) - Blade templates, layouts, interactive modals, and workspace tabs.
