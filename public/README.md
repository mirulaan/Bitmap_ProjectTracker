# Public Web Root Blueprint

## Overview
The `public/` directory is the web server document root (`DocumentRoot`) for **Bitmap Project Tracker**. It hosts the front controller `index.php`, public telemetry scripts, offline font assets, and standalone visualization libraries.

## Subdirectories & Boundaries
- js: [./js/README.md](./js/README.md) - Client-side visualization and styling libraries (Chart.js, Tailwind standalone).
- scripts: [./scripts/README.md](./scripts/README.md) - Industrial telemetry bootstrap scripts and diagnostic packages for factory workstations.
